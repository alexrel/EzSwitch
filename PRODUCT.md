# EzSwitch product context

## Register

product

## Users

Mac users who type with several keyboard layouts and use keyboard shortcuts to switch layouts, correct text, and remember word substitutions.

## Product Purpose

A menu bar utility that makes layout switching and correcting text predictable. Users configure it occasionally and rely on it while working in other applications.

## Brand Personality

Quiet, clear, native. The requested references are macOS settings windows with either sidebar navigation or labeled toolbar icons. The chosen sidebar accommodates the existing keyboard editor and translated section names.

## Anti-references

Oversized menu bar popovers containing every setting, decorative colored cards, hidden clickable labels, and ambiguous controls whose scope is unclear.

## Design Principles

- Keep quick controls in the menu bar and all configuration in one settings window.
- Organize by task and make the scope of global switches and layout-pair rules explicit.
- Open dictionary and character editor links in the pair from which the user navigated.
- Preserve existing mappings, substitutions, shortcuts, and preferences.

## Accessibility & Inclusion

Use native controls, system typography, semantic colors, keyboard navigation, and readable permission states. Support English, Russian, Ukrainian, and Hebrew; physical keyboard diagrams retain their left-to-right arrangement.
